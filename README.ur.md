# Wazuh NoiseLens (اردو)

[English README](README.md)

**Wazuh NoiseLens ایک اوپن سورس کمانڈ لائن ٹول ہے (Python 3.10 یا نیا) جو Wazuh کی ایکسپورٹ کی ہوئی الرٹس فائل کو آف لائن پڑھتا ہے، رول کے حساب سے الرٹس گنتا ہے، اور بتاتا ہے کہ کوئی مجوزہ suppression (الرٹ دبانے کا استثنا) کون سے الرٹس چھپا دے گا، بشمول وہ الرٹس جنہیں آپ نے "محفوظ" قرار دیا ہو۔** یہ ایک آزاد پروجیکٹ ہے، اور Wazuh Inc کے ساتھ اس کا کوئی تعلق یا منظوری نہیں۔

## یہ کس مسئلے کو حل کرتا ہے؟

زیادہ الرٹ دینے والے رول کو چپ کرانا آسان لگتا ہے، مگر اگر استثنا بہت وسیع ہو تو اس کے ساتھ کوئی اہم الرٹ بھی دب جاتا ہے۔ NoiseLens آپ کے پرانے الرٹس پر پہلے ہی حساب لگا کر دکھا دیتا ہے: "یہ استثنا لگایا تو کتنے الرٹس غائب ہوں گے، کتنے بچیں گے، اور کیا کوئی محفوظ الرٹ بھی غائب ہو جائے گا؟"۔ اگر کوئی محفوظ الرٹ دب رہا ہو تو ٹول exit کوڈ 1 دیتا ہے اور جائزہ ضروری ہو جاتا ہے۔

یہ **فیصلہ نہیں کرتا** کہ کون سا الرٹ فضول ہے۔ تعداد زیادہ ہونے کا مطلب غلط الرٹ ہونا نہیں۔ فیصلہ آپ کا رہتا ہے، ٹول صرف اثر ناپتا ہے۔

## کیا کیا دکھاتا ہے

- ہر رول کے الرٹ، کل میں حصہ، اور کتنے الگ ایجنٹس سے آئے (ایجنٹس کے نام رپورٹ میں نہیں آتے)۔
- فائل میں الرٹس کا وقت (UTC میں)، تاکہ پتا چلے کہ آپ نے کس مدت کا ڈیٹا دیکھا۔
- رول گروپس کی میز، مثلاً فائل انٹیگریٹی اور authentication کا حصہ۔
- `--burst-window` سے: ایک رول اور ایک ایجنٹ کے قریب قریب آنے والے الرٹس کو ایک "واقعہ" گن کر دکھانا کہ اصل میں کتنے الگ واقعات ہیں۔
- `--breakdown رول:فیلڈ` سے: کسی رول کے کسی فیلڈ کی سب سے عام قیمتیں، اور `--path-depth` سے راستوں کو چند فولڈرز میں سمیٹنا۔ یہ قیمتیں صرف ٹرمینل پر آتی ہیں، رپورٹ میں کبھی نہیں۔

## فوری آغاز

```sh
python -m noiselens examples/alerts.jsonl --json audit.json --html audit.html
python -m noiselens examples/alerts.jsonl --policy examples/narrow-policy.json --json narrow.json --html narrow.html
python -m noiselens examples/alerts.jsonl --policy examples/broad-policy.json --json broad.json --html broad.html
```

ڈیمو میں 100 مصنوعی الرٹس ہیں۔ تنگ (narrow) استثنا 80 الرٹس چھپاتا ہے اور کوئی محفوظ الرٹ نہیں چھوتا۔ وسیع (broad) استثنا 85 چھپاتا ہے، جن میں 5 محفوظ ہیں، اس لیے نتیجہ 1 اور "REVIEW REQUIRED" آتا ہے۔ Docker سے: `docker run --rm ghcr.io/farhan6667/wazuh-noiselens --help`۔

اپنے ڈیٹا کے لیے، اجازت یافتہ `alerts.json` کو (ہر سطر میں ایک الرٹ) اپنے تجزیے والے کمپیوٹر پر لے جائیں:

```sh
noiselens alerts.json --policy reviewed-exceptions.json --top 20 --json impact.json --html impact.html
```

## اہم حدود، سچ بتانا ضروری ہے

- یہ **ابھی پروٹوٹائپ** ہے اور صرف مصنوعی ڈیٹا پر جانچا گیا ہے۔ اصلی (صاف شدہ) ڈیٹا پر جانچ باقی ہے۔
- "محفوظ الرٹ نہیں دبا" کا مطلب صرف یہ ہے کہ اس ڈیٹا میں نہیں دبا۔ یہ ثبوت نہیں کہ استثنا نئے ٹریفک پر بھی محفوظ ہے۔
- پالیسی صرف تجزیے کا معاہدہ ہے، Wazuh کا XML نہیں۔ منظور شدہ استثنا ہاتھ سے رول میں لکھیں اور اصلی انجن پر جانچیں۔
- ٹول کوئی ڈیٹا نیٹ ورک پر نہیں بھیجتا۔
- لائیو `alerts.json` مینیجر ری اسٹارٹ پر rotate ہوتی ہے، اس لیے ری اسٹارٹ کے فوراً بعد فائل میں بہت کم ڈیٹا ہو سکتا ہے۔ رپورٹ میں دکھائی گئی مدت دیکھ لیں۔

## آپ کیسے مدد کر سکتے ہیں

سب سے قیمتی چیز **اپنے صاف شدہ ایکسپورٹ پر چلا کر بتانا** ہے کہ کیا ٹوٹا یا کیا الجھن بنا۔ کوئی اصلی الرٹ شیئر نہ کریں، تعداد، Wazuh ورژن اور غلطی کا پیغام کافی ہے۔ [CONTRIBUTING.md](CONTRIBUTING.md) میں سیٹ اپ ہے، اور [good first issue](https://github.com/farhan6667/wazuh-noiselens/labels/good%20first%20issue) سے آغاز کر سکتے ہیں۔
